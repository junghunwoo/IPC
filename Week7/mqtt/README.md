# MQTT 기초 → 클라우드 push → 3D 모델 자세 변경 (7주차 예제 묶음)

세 파일이 한 세트입니다. 모두 같은 **토픽 규약**과 **메시지 형식**을 씁니다.

| 파일 | 역할 | 어디서 |
|---|---|---|
| `../mqtt-pose-twin.html` | **구독**: `khu/pcomp/{id}/pose`를 구독해 받은 자세대로 3D 모델(GLB 또는 박스)을 움직임 | 노트북 브라우저 (더블클릭 OK, 제출은 GitHub Pages) |
| `../mqtt-pose-send.html` | **발행(브라우저)**: 슬라이더·프리셋·직접 입력 JSON을 push. 같은 메시지를 다른 도구로 보내는 명령도 표시 | 노트북 브라우저 |
| `push_pose.py` | **발행(파이썬)**: 노트북 터미널에서 paho-mqtt로 push — "브라우저 밖에서도 똑같이 된다"를 보여 주는 예 | 노트북 터미널 |

```
토픽    khu/pcomp/{id}/pose
메시지  {"x":0,"y":0.5,"z":0,"rx":0,"ry":80,"rz":0,"t":1690000000000}
        x,y,z = 위치(m) · rx,ry,rz = 회전(도) · t = 보낸 시각(ms, 지연 계산용) · 빠진 키는 이전 값 유지
```

## 1. 공개 브로커로 따라 하기 (계정 없음)

1. `mqtt-pose-twin.html`을 열고 **ID**(예: 학번 뒷 4자리)를 넣은 뒤 **연결하고 구독**. 상태가 "연결됨 ✔ (공개)"가 되면 됩니다.
2. 다른 창에서 `mqtt-pose-send.html`을 열고 **같은 ID**로 **연결**. 슬라이더를 움직이거나 **문 열기 (ry=80)**를 누르면 트윈의 모델이 돕니다.
3. ③ 칸에 `{"ry":45,"y":0.3}`처럼 직접 써서 push해 보세요. 키를 하나만 보내도 나머지는 유지됩니다.
4. 터미널에서 파이썬으로도 push:
   ```bash
   pip install paho-mqtt            # 처음 한 번
   python3 push_pose.py 1234 --once '{"ry":-90,"y":1.5}'
   python3 push_pose.py 1234        # 4초 동안 한 바퀴 회전
   ```
5. 짝의 ID로 바꿔 연결하면 **짝의 노트북 모델**이 움직입니다. 브로커를 거치면 기기가 어디 있든 상관없습니다.

## 2. 클라우드 브로커(EMQX Serverless)로 옮기기 (계정 필요)

공개 브로커는 누구나 같은 토픽에 쓸 수 있고 언제든 끊길 수 있습니다. 실제 서비스는 **인증이 있는 전용 브로커**를 씁니다.

1. 수업에서 나눠 준 **배포 주소**(`xxxx.ala.ap-southeast-1.emqxsl.com`)와 **계정**(사용자 이름·비밀번호)을 준비합니다. 직접 만들려면 EMQX Cloud 콘솔에서 Serverless 배포를 만들고 *Access Control → Authentication → + Add*로 사용자를 추가합니다.
2. 트윈과 발행기에서 브로커 종류를 **클라우드**로 바꾸고 주소를 `wss://<배포주소>:8084/mqtt`, 계정을 입력한 뒤 연결합니다. (Serverless는 **TLS 포트 8883 / 8084만** 열려 있습니다.)
3. 파이썬은 `--host <배포주소> --user <이름> --password '<비밀번호>'`를 붙이면 8883 TLS로 붙습니다.
4. 무료 한도: 월 트래픽 1 GB, 클라이언트당 발행 10 msg/s. 슬라이더를 마구 흔들지 말고, 자동 회전은 5 Hz(기본)로 두세요.

## 3. 내 스플랫 장면에 같은 원리 적용

`splat-twin.html`은 **센서 규약**(`khu/pcomp/{id}/sensor`, `beta` 각도)을 구독합니다. `twin-control.html`이 그 형식으로 push하는 제어판입니다. 자세 예제에서 배운 것과 구조가 같고, 키 이름만 다릅니다 — 9~11주차 ESP32가 보내는 메시지도 이 형식입니다.

## 막히면

- **"연결 중…"에서 멈춤** → 학교 Wi-Fi가 8084를 막는 경우가 있습니다. 폰 핫스팟으로 바꿔 보세요. 클라우드는 주소 끝에 `/mqtt`가 있는지, 포트가 8084인지 확인.
- **연결은 됐는데 모델이 안 움직임** → ID가 다르거나 토픽 오타. 트윈의 "구독 토픽"과 발행기의 "토픽"을 글자 단위로 비교.
- **"(JSON 아님)"** → 따옴표·쉼표가 빠진 JSON입니다. `{"ry":45}`처럼 키에 큰따옴표.
- **클라우드에서 "오류: Not authorized"** → 사용자 이름·비밀번호가 틀렸거나 그 배포에 없는 계정입니다.
- **파이썬 `No module named 'paho'`** → `pip install paho-mqtt` (맥에서 막히면 `python3 -m pip install --user paho-mqtt`).
