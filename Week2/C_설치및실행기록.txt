5. 작업 폴더 설명
- nerfstudio-data: 기본 SIFT 시도의 중간 데이터(실패 결과)
- nerfstudio-data-hloc: 실제 학습에 사용한 프레임·카메라 데이터
- nerfstudio-output: 설정과 학습 체크포인트
- gaussian-export\splat.ply: SPZ 변환 전 원본 Gaussian PLY
- 과제C.spz: 최종 제출용 파일

6. 남은 수동 작업
- Examples\w02-spz-viewer.html을 브라우저에서 연다.
- 파일 선택에서 IPC_Result\Week2\과제C.spz를 고른다.
- 모델이 보이도록 시점을 조절하고 과제 C 화면 스크린샷을 Week2 폴더에 저장한다.

참고:
- Windows 전역 Python이나 CUDA 설치는 변경하지 않았다.
- Ubuntu 시스템 기본 GCC도 변경하지 않았고, GCC 11은 Pixi 격리 환경에만 설치했다.
- tiny-cuda-nn은 CUDA 11.8과 시스템 GCC 13 충돌로 설치하지 않았으며 Splatfacto/gsplat 작업에는 필요하지 않았다.
