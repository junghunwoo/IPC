A. 트윈 대상 박스 개념화
============================================================

1. 대상 설명
2인실 기숙사 내 방을 가로 6m × 세로 4.5m × 높이 2.5m의 공간으로 설정하고,
오른쪽 벽의 침대 2개와 왼쪽 벽의 책상·의자 세트 2개를 박스 프리미티브로 표현했다.
과제 B와 연결되는 움직일 실물은 주황색으로 표시한 내 의자이며,
웹페이지의 버튼을 누르면 의자가 책상 안쪽과 방 중앙 방향으로 이동한다.

2. GitHub Pages URL
[GitHub에 게시한 뒤 URL 입력]
예상 형식: https://[GitHub아이디].github.io/IPC_Result/Week2/

3. 한 줄 범례
파랑=침대 2개, 갈색=책상 2개, 청록=룸메이트 의자, 주황=내 의자(과제 B 대상)

4. 제출 파일
index.html
[A 결과 화면 스크린샷 파일명 입력]

5. AI 사용 내역 초안
Codex에 room-template.html을 바탕으로 6×4.5×2.5m 크기의 2인실 기숙사 방을 박스로 구성해 달라고 요청했다.
생성된 코드에서 오른쪽 벽에 침대 2개, 왼쪽 벽에 책상과 의자 2세트를 배치하고 내 의자를 움직이는 기능을 추가했다.
실행 화면을 확인한 뒤 의자 등받이의 x 위치를 -0.19에서 0.19로 직접 수정해 책상 반대쪽에 오도록 보정했다.


============================================================
B. AI 기반 모델링
============================================================

1. 대상 설명
과제 A에서 주황색 박스로 표현한 내 의자를 실제 형태의 3D 메시로 만들었다.
Galaxy Note 9으로 촬영한 의자 사진을 Meshy의 Image-to-3D 기능에 입력하고,
실제 의자와 형태가 가장 가까운 생성 결과를 선택해 GLB로 내보냈다.

2. 사용 도구
Meshy - Image to 3D
모델: Meshy 6 Lite
라이선스 표시: CC BY 4.0

3. 제출 파일
과제B.glb (약 6.4MB, 20MB 이하)
과제B.png (입력 사진과 생성 결과 화면 스크린샷)

4. AI 사용 내역 3줄 초안
Galaxy Note 9으로 촬영한 기숙사 의자 사진을 Meshy에 입력하고 사진과 같은 의자를 3D 메시로 생성하도록 요청했다.
생성된 결과들 중 좌판, 등받이와 금속 다리 형태가 실제 의자와 가장 비슷한 결과를 선택했다.
[수정한 내용이 있다면 입력. 수정하지 않았다면: 별도의 형상 수정 없이 선택한 결과를 GLB 형식으로 내려받았다.]

5. 출처 표기 초안
3D chair model generated with Meshy Image-to-3D. License: CC BY 4.0.


============================================================
C. 테스트 스캔 + 내 공간 스캔 계획
============================================================

1. 테스트 스캔 설명 초안
수업 시간에는 강의실 구석 테스트 스캔을 진행하지 않아,
기숙사 방의 의자와 주변 공간을 개인 테스트 스캔 대상으로 대체했다.
Galaxy Note 9으로 촬영한 39초 길이의 일반 RGB 영상을 사용했다.
WSL2 Ubuntu에서 HLOC(SuperPoint + LightGlue)로 296장의 카메라 위치를 모두 복원하고,
RTX 4070 Ti SUPER에서 Nerfstudio Splatfacto를 15,000회 학습했다.
학습 결과를 Gaussian Splat PLY로 내보낸 뒤 Niantic SPZ 도구로 SPZ v4 파일로 변환했다.
최종 결과는 187,409개의 Gaussian으로 구성되며 파일 크기는 약 3.6MB이다.

2. 제출 파일
과제C.spz
[예제 D에서 SPZ를 연 화면 스크린샷 파일명]

3. 내 공간 스캔 계획 3줄 초안
무엇을: 침대 2개와 책상·의자 2세트가 있는 2인실 기숙사 방 중 내 책상과 의자가 있는 구석을 스캔한다.
언제: 낮에 창가의 자연광이 충분하고 룸메이트가 자리를 비운 시간에 촬영한다.
조명·동의: 커튼과 전등으로 밝기를 맞추고 룸메이트의 동의를 받은 뒤 사람과 사적인 물건이 나오지 않도록 정리한다.

4. AI 사용 내역 초안
Codex에 일반 휴대폰 영상과 RTX 4070 Ti Super를 이용해 무료로 Gaussian Splat을 만드는 방법을 질문했다.
Codex가 WSL2 Ubuntu에 Pixi 기반 Nerfstudio 환경을 구성하고, 기본 COLMAP의 특징점 매칭 실패를
HLOC의 SuperPoint와 LightGlue로 다시 처리해 추출한 296개 프레임의 카메라 위치를 모두 복원했다.
이후 RTX 4070 Ti SUPER에서 Splatfacto를 15,000회 학습하고, 결과 PLY를 Niantic의 오픈소스
SPZ 변환기로 압축해 과제C.spz를 생성했다. SPZ 정보 도구로 187,409개 Gaussian과 정상 로드를 확인했다.
